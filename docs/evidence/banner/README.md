# README banner

Before and after for the banner at the top of `README.md`. The top row is the v2
navy and electric blue banner with a microphone glyph. The bottom row is the
SIGNAL banner: black ground, one amber, square corners, and the
waveform-and-caret mark.

Both rows render committed SVGs at 1100 × 340 in a temporary page — the v2
banner from `git show a1fd45d:assets/readme-banner.svg`, the new one from
`assets/readme-banner.svg`. The wordmark is live `<text>` in Bahnschrift, so a
machine without that font falls back to Segoe UI.
