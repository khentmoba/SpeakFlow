## Model catalog

`src-tauri/resources/asr_catalog.json` lists every local model SpeakFlow offers.
It is generated by `scripts/sync_asr_catalog.py` from
[`@handy-computer/models`](https://www.npmjs.com/package/@handy-computer/models)
0.2.3 through the catalog published by
[T3 Code](https://github.com/pingdotgg/t3code/blob/main/apps/server/src/speech/catalog.json).
The catalog records each model's repository, pinned revision, file name, size,
SHA-256, license and published benchmark. No model weights are redistributed in
SpeakFlow's installers; each is downloaded from its own repository when the user
asks for it.

The accuracy grades, error percentages and speed figures shown in the model
browser come from Handy's published benchmark for each model. They were not
measured by SpeakFlow, and they describe that benchmark hardware and audio, not
guaranteed accuracy or latency on a user's PC.

Licenses named in the catalog, by model family:

- Apache-2.0: Whisper, Qwen3-ASR, Cohere Transcribe, Granite Speech, Voxtral,
  Breeze ASR, MOSS Transcribe.
- CC-BY-4.0: Parakeet TDT, CTC and RNNT models, Canary, MedASR's upstream
  release is listed separately below.
- CC-BY-SA-4.0: Orukeet. The share-alike term applies to the model weights the
  user downloads, not to SpeakFlow's source code.
- MIT: Moonshine, GigaAM.
- NVIDIA Open Model License: Parakeet Unified EN 0.6B, Nemotron Speech
  Streaming EN 0.6B and Multitalker Parakeet Streaming 0.6B v1.
- OpenMDW-1.1: Nemotron 3.5 ASR Streaming 0.6B.
- FunASR Model License v1.1: Fun-ASR Nano and Fun-ASR Nano Multilingual;
  SenseVoice Small uses the earlier FunASR Model License.
- Google Health AI Developer Foundations terms: MedASR.

Review the license on each model's repository before redistributing its weights.

## Parakeet models

Parakeet Unified EN 0.6B and Parakeet TDT 0.6B v2 are downloaded separately as
Q8_0 GGUF ports published by
[handy-computer](https://huggingface.co/handy-computer) for transcribe.cpp. They
derive from NVIDIA models and are not redistributed in SpeakFlow's installers.

- [Parakeet Unified EN 0.6B GGUF](https://huggingface.co/handy-computer/parakeet-unified-en-0.6b-gguf)
  is governed by the NVIDIA Open Model License, as stated by the
  [upstream NVIDIA model card](https://huggingface.co/nvidia/parakeet-unified-en-0.6b)
  and the GGUF repository metadata. The transcribe.cpp documentation states
  CC-BY-4.0, which does not match the NVIDIA card. Review the NVIDIA license
  before redistributing these weights.
- [Parakeet TDT 0.6B v2 GGUF](https://huggingface.co/handy-computer/parakeet-tdt-0.6b-v2-gguf)
  is licensed CC-BY-4.0, as stated by the
  [upstream NVIDIA model card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v2).
